### 🚀 About Me

I'm a backend developer focused on building reliable, well-structured APIs and server-side systems with **Node.js** and **NestJS**. I work across the full backend lifecycle — designing database schemas, implementing authentication and authorization, integrating third-party services, and deploying applications with Docker.

- 🔧 I build REST APIs with clean architecture using **NestJS** and **Express.js**
- 🗄️ I design and manage relational and non-relational databases with **PostgreSQL**, **MySQL**, **MongoDB**, **SQLite**, and **Prisma ORM**
- 🔐 I implement secure authentication flows with **JWT**
- ⚡ I use **Redis** for caching and **RabbitMQ** for message queuing in distributed systems
- 📡 I build real-time features with **Socket.io / WebSockets** and document APIs with **Swagger**
- 🤖 I develop **Telegram bots** to automate workflows and services
- 🐳 I containerize and deploy applications with **Docker**, and set up **CI/CD pipelines** with GitHub Actions
- ☁️ I'm familiar with core **AWS** cloud concepts for deployment and infrastructure
- 🌱 Constantly learning and improving my backend engineering skills
